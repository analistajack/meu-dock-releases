# Meu Dock: versões

Instaladores do Meu Dock, o dock pessoal para Windows (Claude, música, tarefas e módulos).

O código fica em outro lugar; aqui só ficam as versões publicadas, em **Releases**. O próprio dock
procura versão nova aqui ao abrir e a cada 6 horas, baixa sozinho e instala quando ele fecha.

Para instalar a primeira vez, baixe o `Meu-Dock-Setup-<versão>.exe` da release mais nova.
